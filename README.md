What is this?

A highly over-engineered coffee machine powered by:

    Microcontrollers

    Web interfaces

    Relays

    Questionable life choices

    Heats water (on purpose)

    Pumps water (mostly where you want it)

    Makes coffee (allegedly)

    Web UI so you can brew from your couch

Requirements

    ESP32

    Coffee

    Low expectations
